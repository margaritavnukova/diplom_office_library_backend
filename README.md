# Дипломный проект студентки ИСПО Политех направления 090207
## Название проекта: "Приложение для буккроссинга в офисе"


### Характеристика проекта
В данном репозитории содержится исходный код бэкенда дипломного проекта. Фронтенд проекта лежит в репозитории по адресу github.com/margaritavnukova/diplom_office_library_frontend
Проект представляет собой кроссплатформенное приложение для браузера, десктопа и телефона. Приложение связывается с базой данных через Web API.

В современном обществе все более популярным такой вид книгообмена, как буккроссинг – свободный обмен бумажными книгами в общественных местах или специально обозначенных для буккроссинга точках. 
Разрабатываемое решение не только оптимизирует внутренние процессы, но и способствует развитию корпоративной социальной инициативы, укрепляя командный дух компании.
#### Цель разработки
Цель разработки – решить проблему ручного учета книг, который в текущем формате приводит к следующим сложностям: 
- сотрудники не могут оперативно узнать, доступна ли нужная книга или кто ее сейчас читает;
- без четкого учета сложно отслеживать перемещение книг, что может привести к их потере;
- новые книги добавляются бессистемно, а популярные издания могут надолго задерживаться у одного читателя;
- ответственные за книгообмен вынуждены тратить время на ручную обработку запросов.
В настоящее время отсутствует централизованная система фиксации данных о взятии и возврате книг, что снижает эффективность процесса.
#### Внедрение приложения позволит:
- повысить эффективность книгообмена за счет сокращения времени на поиск и бронирование литературы;
- минимизировать потери книг благодаря системе учета читателей;
- стимулировать корпоративную культуру чтения, сделав процесс обмена книгами более удобным и доступным;
- создать основу для дальнейшего масштабирования системы (например, интеграции с корпоративным порталом или мобильным приложением).
Таким образом, разработка цифровой платформы для управления офисной библиотекой поможет устранить существующие организационные трудности и оптимизирует процесс книгообмена в компании.


### Функционал приложения
Данная программа должна:
- представлять собой систему управления книгообменом с многоуровневой системой доступа (читатели, менеджеры, администраторы);
- обеспечивать полный цикл работы с книгами;
- позволять управлять учетными записями и правами доступа;
- упрощать ведение электронного каталога книг;
- обеспечивать контроль выдачи и возврата литературы;
- вести учет истории чтения пользователей;
- создавать автоматическое оповещение о просрочках;
- позволять управление профилем пользователя;
- быть предназначена для автоматизации процессов библиотечного обслуживания в корпоративной или образовательной среде. 
Безопасность системы должна быть обеспечена при помощи использования архитектуры Web API, валидации ввода данных, авторизации и разделения ролей


### Используемые технологии
Бэкенд написан на С# ASP.NET с использованием технологии MVC на фреймворке Entity (DB first). Фронт создан при помощи фреймворка Flutter.
Комбинация ASP.NETдля серверной части и Flutter для клиентских приложений представляет собой оптимальный выбор для разработки системы книгообмена по следующим причинам:
- серверная платформа обеспечивает надежность, безопасность и производительность, необходимые для корпоративного решения;
- клиентский фреймворк позволяет создать единое кроссплатформенное приложение с богатым пользовательским интерфейсом;
- экосистема .NET предоставляет все необходимые инструменты для интеграции с корпоративной инфраструктурой;
- решение демонстрирует хорошую масштабируемость и может быть расширено дополнительными функциями.
Данный технологический стек позволяет сократить сроки разработки, обеспечить высокое качество продукта и упростить его дальнейшую поддержку.
